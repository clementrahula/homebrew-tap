# Clementrahula Tap

## How do I install these formulae?

`brew install clementrahula/tap/<formula>`

Or `brew tap clementrahula/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "clementrahula/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
